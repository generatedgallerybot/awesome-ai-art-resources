# Awesome AI Art Resources

A practical list of AI art galleries, prompt libraries, datasets, model hubs, and open tools for exploring generated images.

This is intentionally focused on useful browsing, prompt study, provenance, and open metadata rather than hype.

## Galleries and prompt discovery

- [Generated Gallery](https://generatedgallery.com/) - free AI art gallery with prompts, source links, tags, categories, and SFW/NSFW filtering.
- [Lexica](https://lexica.art/) - Stable Diffusion image and prompt search.
- [Krea](https://www.krea.ai/) - AI image generation and visual inspiration boards.
- [OpenArt](https://openart.ai/) - AI image generation, discovery, and workflows.

- [LandscapioAI](https://www.landscapioai.com/) - AI landscape image generator for turning prompts into outdoor design concepts and visual inspiration.
- [Civitai Images](https://civitai.com/images) - large community gallery for model outputs and prompts.
- [PromptHero](https://prompthero.com/) - prompt examples across image generation models.

## Open metadata and datasets

- [Generated Media Protocol](https://github.com/generatedgallerybot/generated-media-protocol) - JSONL schema for AI-generated images, prompts, provenance, safety labels, and portable gallery packs.
- [Generated Gallery AI Image Dataset](https://generatedgallery.com/ai-image-dataset) - public metadata feed with manifest, sample records, JSON schema, prompts, and source links.
- [LAION](https://laion.ai/) - open datasets and research around image-text data.
- [DiffusionDB](https://poloclub.github.io/diffusiondb/) - prompt and generated image dataset for Stable Diffusion research.

## Model hubs

- [Hugging Face Models](https://huggingface.co/models?pipeline_tag=text-to-image) - text-to-image and image generation models.
- [Civitai Models](https://civitai.com/models) - community model, LoRA, and checkpoint hub.
- [Replicate Explore](https://replicate.com/explore) - hosted AI model demos and APIs.

## Prompt engineering and workflows

- [Prompt Engineering Guide](https://www.promptingguide.ai/) - broad prompt engineering reference.
- [Stable Diffusion Web UI](https://github.com/AUTOMATIC1111/stable-diffusion-webui) - popular local Stable Diffusion interface.
- [ComfyUI](https://github.com/comfyanonymous/ComfyUI) - node-based image generation workflows.
- [InvokeAI](https://github.com/invoke-ai/InvokeAI) - professional creative interface for Stable Diffusion.

## Portable image packs

- [Machine Dream Finds](https://generatedgallery.com/machine-dream-finds) - small themed AI image packs with prompt fragments, source trails, safety labels, and manifests.
- [Generated Gallery Creator Kit](https://generatedgallery.com/protocol/creator-kit) - guide for publishing AI image packs that another viewer or agent can inspect.

## What makes a resource useful here?

Good resources preserve at least some of the context around generated media:

- prompt text or fragments
- model or workflow metadata
- source URLs and provenance
- tags or categories
- safety labels
- exportable feeds, schemas, APIs, or open repos

## Contributing

PRs welcome. Please add resources that are useful for AI art discovery, prompt research, open metadata, model exploration, or reproducible image workflows.

Avoid low-quality tool farms, affiliate-only pages, and sites that hide all useful context behind a signup wall.
